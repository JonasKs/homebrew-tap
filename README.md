# homebrew-tap

Homebrew casks and formulae for Jonas' tools.

## Install

```bash
brew tap jonasks/tap
brew install --cask klepp
```

| Package | What it is |
|---------|------------|
| [klepp](https://github.com/jonasks/klepp) | Small, glassy clipboard manager for Apple Silicon Macs (macOS 26+) |

Casks are updated automatically by each project's release workflow, which opens a PR here.
